[`netbox-pve-sync`](https://git.creekorful.cloud/creekorful/netbox-pve-sync)
project created by Aloïs Micard.

NetBox Sync remains licensed under the GNU General Public License version 3.
[LICENSE.txt](../LICENSE.txt) is the authoritative license text. The current
branding does not claim that the derived work was written from scratch.

The current `main` history is already independent of the legacy fork ancestry.
A clean-root rewrite was considered and is not being performed; the current
NetBox Sync development history is retained. Legacy development history remains
preserved through the original upstream repository and the project's maintained
Git references and archive strategy.
